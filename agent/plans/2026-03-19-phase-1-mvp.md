- Implement the first roadmap phase from `agent/docs/agent-orchestration-platform-plan.md`: a working MVP with project CRUD, kanban UI, task creation and assignment, role config, single-agent dispatch, BYOK management, basic auth, agent output viewing, and Postgres/Redis deployment setup.

## Notes
- Docker is not available in the current execution environment, so compose verification can only be done at the configuration level here.
- Git can be reached by absolute path, but normal repository operations are still constrained by safe-directory ownership checks in this environment.
- The API uses `sql.js` fallback storage when `DATABASE_URL` is unset so the backend can build and test without Docker, while the documented target runtime remains Postgres + Redis.
- A reusable cleanup script was added at `agent/scripts/cleanup-phase1.mjs` with dry-run default and `--apply` delete mode.
